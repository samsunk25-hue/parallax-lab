# 연주시차 탐구소 — 별까지의 거리

중학교 과학 ‘별과 우주’ 단원에서 **연주시차와 별까지의 거리**를 학습하는 단일 파일 웹앱입니다.
설치·회원가입·인터넷 연결이 필요하지 않고, 파일 하나를 열면 태블릿·PC에서 바로 동작합니다.

🌐 **배포 주소: https://samsunk25-hue.github.io/parallax-lab/** (링크만 열면 바로 사용)

👉 앱 파일: [`index.html`](index.html) (같은 내용의 사본: `연주시차_학습앱.html`)

## 구성

| 세션 | 내용 |
|---|---|
| **학습 · 기초** | 우주 시점/밤하늘 시점 시뮬레이터로 거리–시차 반비례를 정성적으로 관찰, 관찰 기록표, 결론 서술(주관식) |
| **학습 · 발전** | `d = 1/p` 계산, 각도(°′″)·거리(AU·ly·pc) 단위 사전, 단위 환산 연습, **거리 비교 스케일 바**(지구–달 ~ 은하 중심) |
| **학습 · 심화** | 표를 직접 계산해 점 찍기, `p–d` 반비례 곡선과 `1/p–d` 직선 비교, 그래프 해석 서술(주관식) |
| **방탈출 퀴즈** | 15유형 랜덤 문제 · **모두 맞혀야 탈출** · 문제를 풀 때마다 **누리호가 한 단계씩 조립**되고 마지막에 발사 · 마지막 문항의 답이 **내 열쇠 숫자**가 되고, 조원들의 숫자를 모아 **모둠 최종 자물쇠**를 엶 |
| **AI 활용 활동** | ① AI가 준 거리 값을 연주시차 자료로 **검산**하고 오차 원인(단위 혼동·d=1/p 미적용)을 진단 · ② 같은 것을 3번 다르게 물어보는 **프롬프트 개선 기록장**(질문 품질 5가지 규칙 자동 점검) |
| **학생 리포트** | 성취기준 도달 현황 + 지식·이해 / 과정·기능 / 가치·태도 3영역 강·약점 방사형 그래프 + 다음 활동 추천 |
| **교사 콘솔** | 학생 현황, 학급별 시각화 대시보드(8종 차트), 문항별 해결 시간, 오개념 통계, 학생별 피드백·과세특 초안, CSV·구글 시트 연동 |

## 사용법

1. `연주시차_학습앱.html` 을 브라우저로 엽니다. (또는 배포된 주소 접속)
2. 학생: 학급·번호·별명 입력 (학습 단계는 **방탈출처럼 관문식**으로 한 관문씩 열리고, 확인 문제는 **한 문제씩** 제시됩니다) → 문제 수준(기본/도전) 선택 → 기초 → 발전 → 심화 → 방탈출.
3. 교사: 상단 **교사 콘솔** → PIN 입력(초기값 `7777테스트`, 콘솔의 수업 설정에서 변경).

### 교사 설정
- **학생용 링크 만들기** — Apps Script URL과 수업 코드를 담은 링크를 배포하면 학생 기기 설정이 필요 없습니다.
- 방탈출 문제 수, 힌트 허용, 계산 허용 오차
- 모둠 협동 잠금 사용 여부 / 최소 열쇠 조각 수 (모둠이 3명·4명으로 달라도 학생이 칸을 추가)
- 결과 수집: CSV 내려받기 · 시트 표 붙여넣기 · (선택) Apps Script 웹앱 URL

## 개인정보 · 안전

- 학습 기록은 **그 기기의 브라우저 저장소에만** 저장되며, 어떤 서버로도 자동 전송되지 않습니다.
- 저장 자료는 난독화하여 보관하고 무결성 검사값을 함께 저장합니다(앱 밖에서 고치면 교사 콘솔에 **변조 의심**으로 표시).
- 문제의 정답은 앱 안에 평문으로 두지 않고 **해시 비교**로 채점합니다. 해설·정답 문자열도 난독화합니다.
- 교사 콘솔에는 이름 표시를 **실명 / 마스킹(김○○) / 코드명**으로 바꾸는 가명처리 기능이 있습니다.
- 결과는 **자동 전송**됩니다: 교사가 만든 학생용 링크로 접속하면 단계 통과·서술 제출·방탈출 완주 때마다 선생님 시트에 자동 기록됩니다(학생이 누를 것은 없습니다). 인터넷이 막힌 교실에서는 **결과 코드**를 대신 쓸 수 있습니다.
- (선택) Apps Script 수집을 켜면 선생님 소유의 구글 시트로만 기록이 전송됩니다.

> 웹앱은 원리상 코드가 학생 기기로 내려갑니다. 위 조치는 콘솔·저장소를 훑어 정답을 얻는 길을 막고 이상 기록을 교사가 탐지하도록 돕는 것으로, 절대적 비밀을 보장하지는 않습니다.

## 접근성 · 학습 지원

- 한 문제에 **5분** 이상 걸리면(관문이 열린 시점부터 계산) 자동으로 **지원 모드**가 열립니다 — 간단한 그림 1개 + 핵심 한두 줄, 선택지 축소(2택), 수치 문제는 3택 전환.
- 문제 읽어주기(브라우저 내장 음성), 표로 보기(그래프 대신), 인쇄·PDF 저장 지원.

## 점검 모드(교사·개발용)

주소 끝에 `?dev=<교사PIN>` 을 붙이면 콘솔에서 `PLX` 로 내부 상태를 확인할 수 있습니다.
예) `index.html?dev=7777테스트` — 학생이 여는 평상 주소에서는 노출되지 않습니다.
